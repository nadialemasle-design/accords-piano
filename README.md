# Accords au piano – révisions par niveau

Application web pour apprendre et réviser les accords au piano, en notation française (Do, Ré, Mi…).

- **Par cœur** : mémoriser fondamentale, tierce et quinte des accords majeurs et mineurs, sans clavier (méthode, cartes, quiz).
- **Niveaux** : 1.1 majeurs/mineurs · 1.2 renversements · 2 diminués, augmentés, sus · 3.1 septièmes · 3.2 renversements des septièmes · 4 extensions et altérations.
- **Modes** : Leçon, Construire, Reconnaître, Écouter.

Un seul fichier `index.html`, sans installation. Pour l'utiliser en ligne : Settings → Pages → branche `main`.
